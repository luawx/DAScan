# 收藏、备注与浏览历史

收藏、备注和标签只保存在客户端本机的 `data/annotations.json`，不会修改 PNG、metadata 或服务器文件。记录以“项目 + 服务器图片路径”为唯一键；取消收藏不会删除仍有备注或标签的记录。

图片页右侧可收藏当前图片、填写备注和逗号分隔标签。“仅看收藏”用于过滤当前项目和日期的图片；顶部“收藏夹”汇总所有项目的收藏，可直接跳转到对应项目、日期和图片。收藏状态和备注在再次查看同一图片时自动恢复。

最近 200 条浏览位置保存在 `data/view_history.json`。图片页的“历史记录”菜单可直接跳转；客户端重新启动后，第一次进入图片页会恢复最后查看的项目、日期和图片。如果项目或服务器图片已被删除，客户端会回退到当前可用位置。
