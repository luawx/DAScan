# Image Viewer

`ImageViewerWidget` 是独立组件，可由预览页和图片浏览页复用。支持自适应窗口、100%、滚轮缩放、拖动、按钮及键盘左右方向键切换。它只接收本地图片路径，不负责 SSH 或缓存。

图片页进入时读取项目输出目录中的 8 位日期目录，选中日期后读取 `index.json`。仅展示 `status=success` 且 `image_path` 非空的记录；选中记录时通过 `ImageService` 下载或复用缓存。右侧将权威 sidecar metadata 按基本信息、数据范围、处理参数、来源文件和版本分组，字段使用中文名称、单位、千位分隔和友好状态文本，并保留未知字段。

图片画布是页面的主要伸缩区域。日期与图片列表合并在窄侧栏，metadata 位于独立右栏；“专注模式”会同时隐藏浏览侧栏、metadata 和应用导航。当前图片显示后会在后台预取相邻图片，最近三张解码后的 QPixmap 保留在内存中，以降低连续切换延迟。

底部进度区区分连接、目录读取、索引读取、排队、SFTP 下载、图片解码、缓存命中和完成。文件下载显示实际字节、百分比、平均速度和 ETA；可折叠队列展示当前与预取任务，默认保持隐藏且不会被传输事件自动展开。当前任务可以取消，取消或失败不会留下 `.part` 文件。

“前后缓存 K”集中在设置页调整，默认并持久化为 3，范围 0–20。选择第 `i` 张时，当前图片以最高优先级读取，同时按“后一张、前一张、后两张、前两张……”的顺序预取前后各 K 张；快速切换时取消新窗口之外尚未完成的预取，避免队列无限增长。
