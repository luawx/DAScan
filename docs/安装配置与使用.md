# DAScan 安装、配置与使用

本文面向需要在服务器上部署批量绘制服务并配合 Windows 客户端使用的用户。仓库中的 `server/` 和 `desktop/` 应使用同一版本。

## 1. 服务器端安装

服务器不能联网时，请由管理员先在可联网机器下载依赖包，再上传到服务器；不要在服务器上直接访问公网。进入代码目录并激活个人 Conda 环境：

```bash
cd /path/to/DAScan/server
conda activate YOUR_ENV
python -m pip install -e . --no-deps --no-build-isolation
plotdas --help
```

运行依赖包括 Click、h5py、Matplotlib、NumPy、PyYAML、SciPy 和 psutil。若环境缺包，应使用与服务器 Python 和系统架构匹配的离线包安装。

## 2. 配置数据源

复制并修改 `server/config/default.yaml`。重点检查输入数据目录、输出目录、任务目录、插件、时区、采样率以及默认通道和绘图参数。源 HDF5 目录建议只读，输出目录和任务目录必须对运行用户可写。

先用检查命令验证数据格式：

```bash
plotdas inspect /data/das/20230308 --limit 3
```

该命令只读取 HDF5 结构和端点，不会绘制整批数据。若接入新的 HDF5 格式，请参考 `server/docs/PLUGIN_API.md` 实现插件。

## 3. 单张绘制

```bash
plotdas plot \
  --project xinjing \
  --start "2023-03-08 12:00:00" \
  --end "2023-03-08 12:01:00" \
  --channel-start 390 --channel-end 882 \
  --filter bandpass --lowcut 2 --highcut 40 \
  --filter-order 4 --dpi 200
```

滤波类型可用 `none`、`bandpass`、`lowpass` 和 `highpass`；截止频率必须小于奈奎斯特频率。已有同名结果需要覆盖时添加 `--overwrite`。

## 4. 批量绘制

指定时间段建立任务：

```bash
plotdas job create \
  --start "2023-03-08 12:00:00" \
  --end "2023-03-08 12:30:00" \
  --channel-start 390 --channel-end 882 \
  --window-length 60
```

对所有可读数据时段建立任务：

```bash
plotdas job create-all \
  --channel-start 200 --channel-end 850 \
  --filter bandpass --lowcut 1 --highcut 50 \
  --dpi 400 --window-length 60 --workers 8
```

随后使用返回的任务编号：

```bash
plotdas job start JOB_ID
plotdas job status JOB_ID
plotdas job list
plotdas job cancel JOB_ID
```

失败时查看 `server/jobs/JOB_ID/log.txt`。任务运行期间不要手工修改 `job.json`。输出目录中的日期子目录包含图片、metadata 和 `index.json`，客户端依赖这些索引浏览结果。

## 5. Windows 客户端安装

```powershell
cd C:\path\to\DAScan\desktop
conda env create -f environment.yml
conda activate plotdas-desktop
python -m pip install -e .
pytest
dascan
```

首次启动默认进入“图片”页。进入“设置”页填写：

- Server Host：SSH 主机名或 SSH config 中的别名。
- SSH Port：服务器 SSH 端口。
- Username：服务器用户名。
- PlotDas Project Path：服务器端 `server/` 的绝对路径。
- PlotDas CLI：服务器环境中运行 CLI 的命令，例如 `conda run -n YOUR_ENV plotdas`。
- SSH Key：可留空并使用 SSH Agent 或默认密钥；密码只保存在本次运行内存中。
- 当前项目和图片数据源：选择项目，并填写该项目的服务器输出目录。
- 磁盘缓存上限：每个项目独立计算，默认为 1 GB；降低额度后保存设置会立即清理最旧文件。

保存后点击“测试连接”。成功状态应同时表明 SSH 可连接、服务器项目目录存在、CLI 可用。

## 6. 图片浏览与收藏

“图片”页按项目和日期读取服务器 `index.json`。选择记录后图片会下载到本地缓存；滚轮缩放范围为 30%–800%，也可使用“适应窗口”和“100%”。右侧详情不会折叠省略，长内容会换行；可在设置页的“详情展示内容”选择所需信息分组。

相邻图片预取采用串行后台策略：当前图片加载完成后，每次只预取一张，完成后再补充下一张，直到覆盖前后 K 张。切换位置时会取消范围外任务；缓存清理不会删除正在下载的 `.part` 或 `.tmp` 临时文件。

收藏时先填写“收藏分组”，也可添加备注和标签。打开“收藏夹”后按分组展开，点击条目会自动切换到对应项目、日期和图片。观看历史自动去重，只保留最近 100 条。

在设置页点击“一键导出收藏”，选择一个父目录。导出结构如下：

```text
选择的目录/
└─ 项目名称/
   ├─ 默认分组.txt
   ├─ 微震.txt
   └─ 爆破.txt
```

每个文本文件每行包含一个收藏事件的开始时间和结束时间，以制表符分隔。没有有效事件时间的旧收藏不会写入时间行，可重新打开图片并保存收藏以补齐。

设置页的“本地存储”区域提供“一键清空全部缓存”。该操作只删除客户端 `cache/` 中下载的图片和 metadata，不会删除服务器原始数据、收藏、备注或观看历史。

## 7. 常见问题

- 连接失败：先在终端验证 SSH 主机、端口、用户和密钥，再检查客户端设置。
- CLI 不可用：确认服务器 Conda 环境、可执行命令和项目安装状态。
- 图片列表为空：确认输出目录存在日期子目录和 `index.json`，并检查项目的数据源设置。
- 绘图失败：检查任务日志、HDF5 格式、时间范围、通道范围和滤波截止频率。
- 客户端显示旧索引：点击“刷新服务器图片”使目录缓存失效后重新读取。
